# Skill: Creación y Formateo de Lecciones Markdown

Esta habilidad define el procedimiento estandarizado para crear o editar lecciones en Markdown dentro del curso **Claude 101**.

---

## Procedimiento de Redacción

1. **Estructura Obligatoria**:
   - `# Lección XX: [Título]`
   - `## Objetivos de Aprendizaje` (4 bullet points procesables).
   - Secciones numeradas `## 1.`, `## 2.`, `## 3.`.
   - Bloques de código con lenguaje explícito.
   - Alertas estilo GitHub Flavored Markdown (`> [!NOTE]`, `> [!TIP]`, `> [!IMPORTANT]`, `> [!WARNING]`).
   - `## Ejercicio Práctico`.
   - `## Resumen y Próximos Pasos`.

2. **Estilo Editorial**:
   - Tono profesional, pedagógico y directo.
   - Tratar a Claude como un **colaborador de pensamiento** (*Thinking Partner*).
   - Evitar jerga confusa sin explicación previa.

3. **Ubicación**:
   - Guarda la lección en el directorio del módulo correspondiente (ej. `01-claude/05-nueva-leccion.md`).
